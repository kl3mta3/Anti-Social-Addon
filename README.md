# Addon working folder

The addon itself is the `AntiSocial` folder. Its contents are the root of the `kl3mta3/Anti-Social-Addon` repository, and its README is [AntiSocial/README.md](AntiSocial/README.md): how to install it, what it does, the commands, the saved data and how to make a release.

The other files here stay out of that repository:

| File | What it is |
|---|---|
| `CURSEFORGE.md` | The description to paste into the addon's CurseForge page. |
| `make-icons.mjs` | Redraws `AntiSocial/Media/icon.tga` and `minimap.tga`. Run it with `node make-icons.mjs`. |

The overall design is in [../DESIGN.md](../DESIGN.md), and what the Forever client allows addons to do is recorded in [../PROBE-TESTS.md](../PROBE-TESTS.md).
